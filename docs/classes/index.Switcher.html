    Class Switcher

    Vision switcher: cuts or moves between live sources, while both keep updating. Defaults apply to every switch unless overridden.

    It updates its sources: don't update them elsewhere.

    See

    https://github.com/Unity-Technologies/com.unity.cinemachine/blob/main/com.unity.cinemachine/Runtime/Behaviours/CinemachineBrain.cs
