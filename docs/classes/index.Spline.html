    Class Spline

    Catmull-Rom spline through points, parameterized by arc length. Points are flat: x, y, z of each point in sequence.

    Centripetal parameterization (alpha 0.5) never forms cusps or self-intersections within a segment, which keeps camera rails smooth.

    See

    Yuksel, C., Schaefer, S. & Keyser, J. (2011). Parameterization and applications of Catmull-Rom curves. https://doi.org/10.1016/j.cad.2010.08.008
