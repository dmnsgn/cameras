    Class Shake

    Trauma based camera shake: hits add trauma, which decays over time, and the shake grows with trauma squared through smooth noise.

    Rotation shake reads better than translation for distant subjects; translation suits close ones.

    See

    Eiserloh, S. (2016). Math for game programmers: juicing your cameras with math. GDC. https://www.gdcvault.com/play/1023557/Math-for-Game-Programmers-Juicing
